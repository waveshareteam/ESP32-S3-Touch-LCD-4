# Support

[中文](SUPPORT_CN.md)

For usage questions and troubleshooting, start with:

- The root README.
- The README for the example you are running.
- The product wiki and schematic.
- Existing GitHub issues.
- [Waveshare support tickets](https://service.waveshare.com/).
- [Waveshare support guidance](https://docs.waveshare.com/support).

When opening an issue, include the board revision, example path, framework version, reproduction steps, and relevant serial log. Remove secrets such as Wi-Fi passwords, tokens, and private URLs before posting logs.

For order-specific support, warranty questions, hardware replacement, or private logs, open an [official Waveshare support ticket](https://service.waveshare.com/) and include the product model and order information.
