# Support

For usage questions and troubleshooting, start with:

- The root README.
- The README for the example you are running.
- The product wiki and schematic.
- Existing GitHub issues.

When opening an issue, include the board revision, example path, framework version, reproduction steps, and relevant serial log. Remove secrets such as Wi-Fi passwords, tokens, and private URLs before posting logs.

For order-specific support, warranty questions, or hardware replacement questions, contact Waveshare support through the official support channel and include the product model and order information.
